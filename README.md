# Book Giveaway Name Picker

A small browser application that imports participant names and randomly selects a winner for a book giveaway.

## Project goal

Replace a manual drawing process with a transparent, easy-to-use browser tool that can run without a backend.

## Features

- Load a list of participant names
- Randomly select a winner
- Display the selected participant
- Run entirely in the browser

## Technologies

- **HTML**
- **CSS**
- **JavaScript**

## What I learned

- Turning a real operational need into a small tool
- Parsing and managing user-provided lists
- Implementing random selection in the browser
- Designing a focused single-purpose interface

## Running locally

Open `index.html` in a browser.

## Project status

This is a learning project and is not presented as a production-ready application.
